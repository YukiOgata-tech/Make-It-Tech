## 1. カバー画像（サムネイル）

| 項目 | 指定 |
| --- | --- |
| ファイル名 | `public/images/blog/subsidy-website-cover.webp` |
| 寸法 | **1200 × 630 px**（変更不可） |

| alt | 補助金でホームページは作れるのかを解説する記事のカバー画像 |

**なぜこの寸法か**：この画像はそのままOGP画像になります。X・Facebook・LINEで共有されたときのカードがこの1枚です。1200×630 はそのための比率なので、別の比率にすると端が切れます。

**中身のイメージ**：

- 記事タイトルをそのまま載せる必要はありません。既存のカバーと同じく、**短い言葉＋モチーフ**の構成にしてください
- 文字を入れるなら「補助金でホームページは作れる？」程度の短さで。SNSのタイムライン上ではかなり小さく表示されるので、10文字前後が限界です
- モチーフ案：申請書類とノートパソコン / 商工会議所の窓口をイメージさせる机まわり / 電卓と見積書
- 写真でもイラストでも構いませんが、既存7記事のカバーとトーンを合わせてください
- **金額（30万円、50万円など）は入れないでください。** 制度が変わると画像だけ古くなり、差し替えが必要になります

**避けたいもの**：日本の補助金制度の記事なので、海外のオフィス写真や英語の書類が写っているストック画像は避けてください。

### 生成プロンプト

```
1200x630のブログサムネイル。明るい木製デスクを俯瞰で、背景に観葉植物をぼかす。
白基調、日本のビジネス系サイトのトーン。

右半分：申請書類・ノートパソコン・電卓・ペンを自然に配置。
書類はピントを浅くして文字が読めないようにする。

左半分：太いゴシック体で3行
補助金で / ホームページは / 作れる？
「作れる？」だけ濃い緑、他はダークグレー。
その下に小さく「通る使い方と、通らないケース」。

金額・英語・人物の顔は入れない。
```

緑は既存カバーからスポイトで拾って合わせてください。

生成後の確認：**日本語が崩れていないか**（崩れたら背景だけ生成して文字は後載せ）、**1200×630ちょうどか**、**WebP q82 で書き出したか**。
