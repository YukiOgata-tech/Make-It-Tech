## 本文

「ホームページを作りたいのですが、補助金は使えますか」

事業者の方から、この質問をよく受けます。

答えは「使えます」です。ただし、多くの方が想像している形とは少し違います。

補助金は「ホームページ制作費を出してくれる制度」ではありません。**販路を開拓するための取り組みを支援する制度**で、ホームページはその手段のひとつとして認められている、という位置づけです。

この違いを理解しないまま申請すると、書類が通りません。

この記事では、ホームページに使える補助金と使えない補助金、そして申請の前に決めておくべきことを整理します。

## 結論：持続化補助金なら作れる。ただしホームページ単体では申請できない

先に結論を書きます。

- ホームページ制作に使えるのは **小規模事業者持続化補助金**
- ウェブサイト関連費として計上できるのは **上限30万円（税込）**
- **ウェブサイト関連費だけの申請は認められない**
- デジタル化・AI導入補助金（旧IT導入補助金）では、ホームページそのものは作れない

つまり「ホームページを作りたいから補助金を申請する」という順番では通りません。

「販路を広げるためにこういう取り組みをする。その一部としてホームページを作る」という順番になります。

## ホームページに使えるのは「小規模事業者持続化補助金」

小規模事業者持続化補助金は、小規模事業者が販路開拓に取り組むときの費用を補助する制度です。

商工会議所または商工会の管轄地区ごとに事務局が分かれていて、申請には事務局の窓口を通す必要があります。

第20回公募要領（2026年5月27日公開）時点の条件は次のとおりです。

| 項目 | 内容 |
| --- | --- |
| 補助率 | 2/3（賃金引上げ特例の場合は3/4） |
| 補助上限 | 50万円 |
| インボイス特例 | 上限に50万円を上乗せ |
| 賃金引上げ特例 | 上限に150万円を上乗せ |
| ウェブサイト関連費 | 上限30万円（税込） |

### 2026年の第20回で「4分の1ルール」がなくなった

ここが今年いちばん大きな変更点です。

第19回までは、ウェブサイト関連費に **交付申請額の4分の1まで** という制限がありました。

補助金を50万円で申請するなら、ウェブサイトに使えるのは12万5千円まで。ホームページを作るには足りない金額です。この制限のせいで諦めた事業者を何人も見ています。

第20回では、この4分の1ルールが廃止されました。かわりに **ウェブサイト関連費は30万円（税込）まで** という上限だけが残っています。

小さな事業計画でも、ウェブサイトに30万円まで充てられるようになったということです。ホームページ制作にとっては、明確に使いやすくなりました。

![補助対象経費のうちウェブサイト関連費が占められる範囲](/images/blog/subsidy-website-scope.svg "preset:full-center")

### ウェブサイト関連費だけの申請は通らない

上限が緩んだ一方で、変わっていない条件があります。

**ウェブサイト関連費だけを計上した申請は認められません。**

広報費（チラシ、看板など）、機械装置等費、展示会等出展費といった他の経費区分と組み合わせる必要があります。

そのため実際の申請は、たとえば次のような形になります。

- ホームページ制作 30万円 ＋ チラシ・ショップカードの制作 20万円
- ホームページ制作 30万円 ＋ 店頭看板の設置 25万円
- ホームページ制作 30万円 ＋ 展示会への出展費 30万円

ホームページを起点にしつつ、そこへ人を送る手段をセットで考える。補助金の要件としてそうなっているだけでなく、**集客の設計としても、この組み合わせは正しい**と考えています。

## デジタル化・AI導入補助金ではホームページは作れない

もうひとつよく聞かれるのが、IT導入補助金です。

この制度は令和7年度補正予算事業から **デジタル化・AI導入補助金** に名称が変わりました。補助額は最大450万円、補助率は1/2〜4/5と、金額だけ見れば持続化補助金より大きい制度です。

ただし、**ホームページ制作には使えません。**

### 対象は「ITツール」であって、ホームページそのものではない

この補助金の対象は、事務局に登録されたITツール（ソフトウェア）です。2026年からは「AI機能を搭載したツール」という方向へ定義が絞り込まれました。

申請には、登録されたIT導入支援事業者と組む必要もあります。

ホームページのデザインや制作にかかる費用は、この枠組みの外にあります。予約管理システムのような機能部分が対象になる可能性はありますが、それは「ホームページを作る補助金」ではありません。

### ECサイトは新規のEC機能だけが対象

ネットショップについても誤解が多い部分です。

対象になるのは、**新しくEC機能を実装する場合**に限られます。既存サイトのリニューアルは対象外です。

「補助金でネットショップをきれいに作り直す」という使い方はできない、と考えてください。

## 補助金の相談を受けたとき、私が先に確認すること

制度の条件よりも、実務ではこちらのほうが重要です。

### そのホームページで何を売るのか

補助金の審査は、経営計画と補助事業計画で決まります。

「ホームページがないので作りたい」だけでは計画になりません。誰に何を届けて、その結果どう売上が変わるのか。ここが書けないうちは、制作の見積もりを取る段階ではありません。

### 補助金の額に合わせてサイトの規模を決めていないか

30万円という上限が先にあると、そこへ合わせて内容を決めたくなります。

ですが、事業に必要なサイトの規模は補助金の上限とは無関係です。順番が逆になると、補助金は取れたのに使えないサイトが残ります。

必要なものを決めてから、そのうちどこまでを補助対象にできるかを考える。この順番は崩さないでください。

### 交付決定の前に発注していないか

これが最も多い失敗です。

補助金の対象になるのは、**交付決定を受けたあとに発注し、支払った経費**です。採択発表を待たずに制作を始めてしまうと、その費用は対象外になります。

「早く作りたい」という気持ちはよくわかりますが、ここだけは急がないでください。

## 第20回は、締切の前にもう一つの締切がある

スケジュールで注意すべき点があります。

![第20回のスケジュールと様式4の締切](/images/blog/subsidy-website-schedule.svg "preset:full-center")

第20回の申請受付は2026年11月5日から、締切は12月15日17:00です。

ただし、申請には商工会議所または商工会が発行する **事業支援計画書（様式4）** が必要で、その発行受付締切は **12月4日** です。申請締切の11日前に、もうひとつの締切があります。

様式4は窓口へ相談して発行してもらう書類なので、当日に受け取れるものではありません。年末が近づくほど窓口は混みます。

逆算すると、**10月中には計画の相談を始めておきたい**ところです。今から準備を始めれば十分に間に合います。

## 補助金を使わない、という選択肢

ここまで書いておいてなんですが、補助金ありきで進めないほうがよい場合もあります。

採択発表は2027年3月頃です。それまで待てない事業であれば、先に小さく作り始めたほうが早く回収できます。

その場合におすすめしているのが、更新できる部分を絞ってCMS化する作り方です。最初から大きく作らず、必要なところから育てていく考え方については[自分で更新できるCMS型サイトという選択肢](/blog/cms-partial-update-website)で詳しく書きました。

また、ホームページは作った時点では見てもらえません。作ったあとにどう人を集めるかについては[サイトへのアクセスを増やすことが、そのままMEO対策になる](/blog/site-access-meo)を読んでみてください。補助金の要件である「ホームページと他の販路開拓策の組み合わせ」は、そのまま集客の設計としても理にかなっています。

## まとめ

- ホームページ制作に使えるのは小規模事業者持続化補助金。ウェブサイト関連費の上限は30万円（税込）
- 第20回で4分の1ルールが廃止され、使いやすくなった
- ウェブサイト関連費だけの申請は通らない。他の経費と組み合わせる
- デジタル化・AI導入補助金ではホームページは作れない
- 交付決定の前に発注しない
- 様式4の発行受付締切（12月4日）が実質の締切
