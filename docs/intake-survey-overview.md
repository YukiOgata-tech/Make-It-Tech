# 業務診断・制作相談アンケート概要

このアンケートは、業務診断に加え、WEBサイト制作・LP・ECなどの制作相談にも対応するための共通フォームです。
LINEや問い合わせ後にURLを共有し、具体的な要件を整理してもらう目的で使います。

## 利用想定
- 業務診断の初回ヒアリング
- WEBサイト制作の要件整理
- LP制作の要件整理
- ECサイト構築の要件整理
- DX関連（業務改善・自動化）の相談
- 相談内容が未定のケース

## フロー（全4ステップ）
1. 基本情報
2. 要件ヒアリング（依頼種別によって内容が切り替わる）
3. 目的・ゴール
4. 制約・補足

## 依頼種別（選択必須）
- WEBサイト
- LP
- EC
- DX関連（業務改善・自動化）
- その他

## ステップ別の内容

### 1. 基本情報
- お名前
- メールアドレス
- 会社名・屋号
- 電話番号（任意）
- 業種
- 従業員規模
- 依頼種別（上記から選択）

### 2. 要件ヒアリング（依頼種別で切替）

#### WEBサイト
- 目的・背景
- 必要ページ・構成
- 現サイトURL（任意）
- 参考サイト（URL可）
- 原稿・写真・ロゴの有無

#### LP
- 目的・コンバージョン
- 商材・サービス内容
- ターゲット
- 参考LP（URL可）
- 原稿・素材の有無

#### EC
- 商材・商品点数
- 希望プラットフォーム
- 決済・配送
- 在庫・運用
- 参考サイト（URL可）

#### DX関連（業務改善・自動化）
- 対象業務の内容
- 現在使っているツール
- 件数・頻度
- 関わる人数・担当

#### その他
- 相談したい内容
- 目指したい状態

### 3. 目的・ゴール
（DXの場合は「課題と理想」として扱う）
- 背景・課題（または困っていること）
- 目的・ゴール（または理想の状態）
- 成功指標（任意）

### 4. 制約・補足
- 予算感（任意）
- 希望納期（任意）
- 決裁者（任意）
- 制約・注意点（任意）
- 補足事項（任意）
- 資料・画像添付（任意）
  - 最大10件 / 合計20MB
  - 画像は自動で軽量化

## 入力の方針
- 各項目は「指定なし（提案希望）」として未確定でもOK
- 迷っている内容は空欄でも送信可能
- 依頼種別に合わせて必要な質問だけ表示

## 管理側での活用
- 依頼種別で自動分類
- 管理画面で種別ごとの要件を確認可能
- 業務診断と制作相談を同一フォームで一元管理
