# 事業運営に必要な法的事項と用意しておくと良い文書

本書は「Make It Tech（DX支援・業務改善・Web制作）」を、**広告に依存せず、直接営業や紹介で案件獲得する**前提での整理です。  
※法的判断は専門家（弁護士・税理士・社労士など）に確認してください。

## 1. 法的に押さえるべき事項（優先度高）

### 個人情報保護法（APPI）
- 問い合わせフォーム、名刺、LINEなどで個人情報を扱う場合は適用されます。
- 取得目的の明示、適正な取得、安全管理措置が必要です。
- すでに公開している「プライバシーポリシー」は実運用と一致させる。

### 特定電子メール法（広告宣伝メール）
- メール営業を行う場合、原則オプトイン（事前同意）と送信者情報の表示、配信停止手段の明記が必要です。
- 紹介経由でも、同意の有無を記録しておくと安全です。

### 特定商取引法（該当する場合のみ）
- 「訪問販売」「電話勧誘販売」「通信販売」など該当形態がある場合、表示義務などが発生します。
- B2B中心でも、形態によって適用される可能性があります。

### インボイス制度（必要に応じて）
- 取引先が適格請求書を要求する場合、事業者登録と登録番号の記載が必要です。
- 見積書・請求書の様式にも影響します。

## 2. 用意しておくと良い文書（営業・紹介に強い）

### 会社/サービス概要1枚（PDF）
- 紹介や初回説明時に使える最重要アイテム。
- サービス範囲、強み、支援スタイル、料金感の概要を1枚に。

### 業務診断ヒアリングシート
- 「現状」「理想」「制約（予算/納期/担当者）」を短時間で整理。
- 相談の質と提案の精度が上がります。

### 提案書テンプレート
- 課題 → 方針 → 範囲 → 成果物 → スケジュール → 料金の流れが基本。
- 変更対応や除外範囲も記載すると誤解が減ります。

### 見積書テンプレート
- 作業範囲、納期、前提条件、有効期限、検収条件を明確に。

### 基本契約＋個別契約（SOW）
- 「範囲」「検収」「変更（追加費用）」「納期」「成果物の権利」などを整理。
- DX/業務改善は範囲が膨らみやすいので必須に近いです。

### NDA（秘密保持契約）
- 初回相談時の安心材料。紹介経由の信頼獲得にも有効。

### 運用・保守の合意書
- 月額支援や改善サイクルを前提にする場合は必須。
- 「対応範囲」「対応時間」「回数」「緊急対応」などを明確化。

## 3. 紹介・直接営業向けに効く運用資料

### 紹介依頼テンプレ
- 紹介者が送るための短い文面を用意（LINE/メール用）。
- 「どんな人に向くか」「何を相談できるか」を短く明記。

### 事例・実績まとめ（ビフォー/アフター形式）
- 結果の数字（時間削減・問い合わせ数改善など）を短く入れると強い。

### 初回ヒアリング用スクリプト
- 10分で要点を聞き切るための質問順序を固定化。

## 4. 直接営業・紹介を回すときの注意

- 送信メールや紹介時に「同意の有無」が不明な場合は配慮が必要
- 「範囲と責任の明確化」を最優先にする
- 最初に「作らない」提案も含めることで信頼が増す

---

必要なら、実際のテンプレ文書（提案書/見積/ヒアリングシート）の雛形も作成します。
