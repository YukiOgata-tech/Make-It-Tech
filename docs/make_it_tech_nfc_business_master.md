# Make It Tech NFC事業 概要・商品仕様

最終更新：2026年8月8日

---

## 1. 事業概要

Make It Tech NFC事業は、店舗・事業者向けに、NFCを利用した各種Web導線を物理スタンド・プレートとして提供する事業である。

単なるNFCタグ販売ではなく、必要に応じてNFCへのリンク設定まで行い、届いた後すぐに利用できる完成品として販売する。

主な用途は以下のとおり。

- Googleレビューへの導線
- Googleマップ等への導線
- Instagram、TikTok、X等のSNSへの導線
- LINE公式アカウントへの導線
- Webサイトへの導線
- ECサイトへの導線
- 飲食店のデジタルメニュー表示
- 予約ページへの導線
- アンケートフォームへの導線
- クーポン・キャンペーンページへの導線
- 採用ページへの導線
- その他、URLでアクセス可能なページへの導線

基本方針として、物理製品の販売を中心とし、購入から利用開始まで製品単体で完結できるビジネスモデルとする。

Googleビジネスプロフィールの登録代行、Webサイト制作、MEO支援等の周辺サービスはMake It Tech本体で提供可能だが、本NFC事業内では強く訴求せず、必要な顧客のみMake It Tech公式サイトへ案内する。

## 4. デザイン区分

商品デザインは以下の3種類に分類する。

### 4.1 デフォルトデザイン

Make It Tech側であらかじめ用意した既定デザインから選択する。

- デザイン変更不可
- 商品一覧から選択
- 白・黒等の商品バリエーションを用意する想定
- NFC設定サポートを基本価格に含む

LP・チラシでは主力商品として訴求する。

---

### 4.2 オリジナル印刷モデル

顧客独自のロゴ、ブランド、デザイン等を使用した印刷商品。

#### 入稿データがある場合

- デザイン制作費：0円
- 顧客から完成済みの入稿用データを受領
- 商品への印刷・NFC設定を行う

#### Make It Techにデザイン制作を依頼する場合

- 商品価格に加えてデザイン制作費：+5,000円
- メールまたはMake It Tech公式LINEでヒアリング・チャット対応
- 1つのデザイン案を商品化するための制作を基本とする

デザイン制作の具体的な修正回数・対応範囲は今後確定する。

---

### 4.3 無地モデル

印刷・装飾を行わない無地商品。

顧客側でステッカー貼付、印刷、加工、独自運用等を行いたい場合を想定する。

#### 基本価格

- 2,480円 / 1個
- NFC設定なし

#### シンプルNFC設定オプション

- +1,500円 / 1注文または1商品単位を想定
- Googleレビュー、SNS、Webサイト等、単一URLへのシンプルな設定を対象

複雑なNFC機能やMake It Techドメインを利用した構築は対象外。

無地モデルはECサイト限定で販売する。

LP・営業用チラシでは原則として強く訴求せず、主力商品のデフォルトデザイン・オリジナル印刷モデルを中心に案内する。

## 5. NFC対応内容

### 5.1 標準対応

標準的なNFC設定では、NFCタグにURLを設定し、スマートフォンをかざした際に指定ページを開く。

対応例：

- Googleレビュー投稿ページ
- Googleマップ
- Instagram
- TikTok
- X
- Facebook
- LINE公式アカウント
- Webサイト
- ECサイト
- デジタルメニュー
- 予約ページ
- アンケート
- クーポンページ
- 採用ページ
- その他URL

基本的に、URLでアクセス可能な既存ページへの導線構築を標準対応範囲とする。

## 6. NFC設定サポートの範囲

### 標準価格に含むもの

デフォルトデザインおよびオリジナル印刷モデルでは、以下を基本価格に含む。

- 顧客指定URLの確認

- NFC読み取り確認
- 製品発送前の基本動作確認

### 標準価格に含まないもの

以下はNFC商品価格には原則含まない。

- Googleマップ掲載のための各種設定
- SNSアカウントの開設
- LINE公式アカウントの開設・構築
- Webサイト制作
- LP制作
- デジタルメニュー自体の制作
- MEO運用
- SNS運用
- 広告運用
- その他、リンク先サービスそのものの制作・運用

リンク先が存在しない場合や周辺サービスまで必要な場合は、必要に応じてMake It Tech公式サイトへ案内する。

## 9. まとめ買い割引

一般顧客向けには5個単位のまとめ買い割引を設ける。

### 基本ルール

5個購入ごとに1個分を無料相当とする。

つまり、

- 5個購入 → 4個分の価格
- 10個購入 → 8個分の価格
- 15個購入 → 12個分の価格

### デフォルトデザイン スタンド・プレート

通常価格：4,980円 / 個

| 数量 | 通常価格 | 割引後価格 |
|---|---:|---:|
| 1個 | 4,980円 | 4,980円 |
| 5個 | 24,900円 | 19,920円 |
| 10個 | 49,800円 | 39,840円 |
| 15個 | 74,700円 | 59,760円 |

## 15. LPの基本方針

LPでは無地商品の訴求はほぼ行わない。

主力として以下を訴求する。

- デフォルトデザイン
- オリジナル印刷モデル
- NFC設定まで対応
- 1個から注文可能
- 5個ごとのまとめ買い割引
- Googleレビュー・SNS・メニュー等に対応
- 大量注文・法人導入にも対応
- 高度なカスタマイズは要問い合わせ

LPの主目的は、NFCの仕組みを理解させることではなく、

**「店舗で何に使えるか」**
**「導入すると何が楽になるか」**
**「購入後すぐ使える」**

ことを分かりやすく伝え、Shopify ECまたは問い合わせへ誘導することとする。

## 20. 現時点の事業要約

Make It Tech NFC事業は、Googleレビュー、SNS、メニュー、Webサイト等への導線をNFCスタンド・プレートとして販売する。

主力商品は、

1. デフォルトデザイン
2. オリジナル印刷モデル

の2系統とし、無地モデルはShopify EC限定商品として扱う。

デフォルトデザイン・オリジナル印刷モデルではNFC設定まで基本価格に含み、顧客が完成品としてすぐに利用できる状態で提供する。

ECはMake It Techドメイン配下のShopify用サブドメインで運営し、別サブドメインにNFC事業LP、カスタマイズ、情報送信、高度なNFC構築ページ等を配置する。

一般店舗への1個単位販売を基本としながら、複数個割引、大量注文、法人導入、コンサルティング会社等への一括提供にも対応する。

Web制作やGoogleビジネスプロフィール等の周辺サービスはMake It Tech本体で提供可能だが、本事業ではあくまでもNFC製品販売を中心とし、必要な場合のみ本体サービスへ案内する。
